02 // HOW IT WORKS

Move, jump, duck — the gun handles itself

Neon Runner strips the shooter down to movement. You have no fire button to press: weapons auto-target and auto-fire at anything in range, so every second is spent reading the level and dodging.

Run left←A
Run right→D
Jump↑W
Duck / slide↓S
Jump / confirmSpaceEnterZJ
PauseP
Back / cancelEscBackspace
Pick an upgrade card←→Enter

Between levels you choose from upgrade cards — crit chance, coolant, boost jets and more. Keys are fully rebindable from the in-game Controls screen; on phones, on-screen touch controls appear automatically.

05 // FAQ

Questions, answered

What exactly is Neon Runner?
A retro auto-fire side-scrolling shooter. You control movement only — run, jump and duck — while your gun automatically fires at enemies in range. It is delivered as one self-contained HTML file.
Do I need to install anything?
No. It runs in any modern browser, desktop or mobile. You can also download the single index.html and open it directly from your filesystem.
Does it work offline?
Yes. Once the page has loaded, Neon Runner makes no network calls — all art, sound and music are generated at runtime. Close the Wi-Fi and keep playing.
Can I use the keyboard?
Absolutely. Arrow keys or WASD to move and jump, Space/Enter to confirm, P to pause, Esc to go back. Every action is rebindable from the in-game Controls screen.
Is there a high score to beat?
There is — the game tracks your best run and shows a live score with chain multipliers as you take down enemies. Chasing that number is half the fun.
What is the licence?
MIT. Fork it, remix it, ship your own version — the full source is in the GitHub repo.
